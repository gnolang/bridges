# The bridge in seven pictures

Each board is a PNG and the plain HTML page it was drawn from (1600 × 1140, IBM Plex Sans from Google Fonts). Open
the HTML in a browser to read or edit a board; the PNG is that page at twice the scale.

Colour is the kind of trust: teal is a check code makes, orange a party that is believed, purple a brake that can
only stop, grey a carrier that decides nothing. The boards state rules, not today's head counts: the validator set
and GovDAO's membership change, and the boards hold either way. They follow `PLAN.md` v36: one governor key decides
until it yields to GovDAO, and GovDAO decides from the yield.

To re-render a page: a headless browser at a 1600 × 1140 viewport and a device scale of 2, screenshot the page.
