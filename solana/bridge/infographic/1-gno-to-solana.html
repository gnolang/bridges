> 2/3 of the voting power must sign — N validators, whoever GovDAO has set and however many; the light client follows every change of the set. A validator asleep (grey) changes nothing while > 2/3 of the power signed. These signatures are the proof; no machine of the operator's can forge them.
If GovDAO changes the set: the next header announces it, Solana follows the change and pauses minting 7 days (the quarantine) — time for the guardians to hold.
What Solana must trust here: only that > 2/3 of this power is honest. A leak of the current set's keys is a permanent capture of the Solana side.

light-client program of gno.land (on Solana)
keeps: the last trusted header · the validators' keys and powers
update(header H, signatures)
✓ valid ed25519 signatures over H's hash from > 2/3 of the current set's power · ✓ H follows the last trusted header
verify(message ✉, path hashes)
✓ rebuild the root from ✉ and its path hashes · ✓ it equals LastResultsHash in trusted header H · ✓ the leaf has no error and is hlmailbox's
Every check is pure arithmetic on chain (the ed25519 precompile, sha256). Nothing is believed.
The same path carries the governor's decisions (GovDAO's from the yield) to the admin program.
